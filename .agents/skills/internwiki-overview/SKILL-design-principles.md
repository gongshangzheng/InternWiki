# UI/UX 设计公约

记录 InternWiki 前端的设计公约，确保不同页面风格一致。裁剪自 ProjFlow design-principles skill（移除了训练平台专属的分页 API/视频封面/数据集页 references 与 Vue 组件示例）。

## 1. 状态色统一

- 进行中/active → 绿 `#22c55e` · 待开始/planned → 蓝 `#3b82f6` · 已完成/completed → 灰 `#71717a` · 暂停/paused → 黄 `#eab308` · 阻塞/blocked → 红 `#ef4444`
- 状态用圆点 + 文字标签，不用彩色大色块

## 2. 空状态不报错

数据为空时显示一句话说明"为什么空 + 怎么让它有数据"（如 InternWiki 现有 `cfg.empty` 文案），不是空白或报错。

## 3. 悬浮卡 vs 详情页

悬浮卡 = 轻量预览（3-5 个关键字段）；超过 5 个字段或需要滚动 → 做详情页。

## 4. 表单验证

必填字段 `*` 标注；错误提示贴输入框下方（toast 留给成功/系统级错误）。

## 5. 响应式断点

桌面端优先（最小 1024px）。卡片网格用 CSS `repeat(auto-fill, minmax(Npx, 1fr))` 自适应；文档侧栏在 `lg` 以下隐藏（现有约定）。

## 6. 加载状态

< 500ms 不显示加载态（避免闪烁）；> 500ms 用骨架屏或"加载中…"。

## 7. 错误处理

瞬时失败不中断整体渲染；错误信息展示在出错位置附近，不吞进控制台。

## 8. 加载性能

- 路由懒加载；`<img loading="lazy">`；缩略图 < 100KB/张，原图只在详情层
- 长列表考虑分页或虚拟滚动（树形结构天然折叠可例外）
- 搜索框 debounce
