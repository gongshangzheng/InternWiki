## Why

数字人模型探索中，“跑过但当前未采用”的结果分散在命令记录、截图和临时目录里。若只记录最终选中的 Avatar Forcing，会丢失 ExOmni-2D、MoDA 等模型为何暂不选用、哪些条件尚未公平比较的关键上下文，也容易把一次未复现的观察误写成永久失败结论。

## What Changes

- 新增《模型探索与未采纳实验复盘》专题文档，记录模型、实验和当前决策状态
- 用状态而不是“失败模型”标签管理结论：待复跑 / 初步观察 / 已复现 / 已否决
- 固定每条记录的证据字段：模型版本与来源、输入资产、驱动音频、硬件和关键参数、观察维度、对照对象、证据路径、当前结论、下一步
- 明确可复现协议：只有同资产、同音频、同分辨率/帧率、同硬件预算或明确差异后，才可做模型间比较
- 创建两条待复跑占位：ExOmni-2D（初步观察：输出偏糊）、MoDA（初步观察：可运行但当前主观上弱于 Avatar Forcing）；不记录为最终结论
- 文档包含“未采纳实验的价值”、状态流转、失败测试记录模板和面试追问预案
